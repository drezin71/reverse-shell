# reverse-shell
# TCP Shell em C#

Fiz esse projeto pra estudar sockets em C# e entender melhor como funciona a comunicação TCP no Linux.

Por enquanto, é uma implementação básica com um cliente e um listener, troca de mensagens e execução de comandos no sistema.

Ainda tem bastante coisa pra melhorar. Estou usando o projeto pra aprender na prática e entender melhor o que acontece por trás da comunicação.

Feito durante meus estudos de C# e segurança da informação.
